# 🌐 메리츠 AI 자동 주식 트레이더 - Web 버전 배포 패키지

## 1. 개요
Chrome, Edge, Safari, Firefox 등 모든 웹 브라우저에서 실행 가능한 크로스 플랫폼 PWA 웹 애플리케이션입니다.

## 2. 로컬 실행 방법
1. `run_web.bat`을 더블 클릭합니다.
2. 자동으로 브라우저에서 `http://localhost:8080/index.html`이 열립니다.
3. 또는 `index.html`을 더블 클릭하여 바로 여셔도 됩니다.

## 3. PWA (앱으로 설치) 지원
- Chrome / Edge 주소창 우측의 **[앱 설치 ➕]** 아이콘을 누르면 PC 바탕화면에 독립 앱으로 설치됩니다.
