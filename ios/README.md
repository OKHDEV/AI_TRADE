# 🍎 메리츠 AI 자동 주식 트레이더 - iOS (아이폰/아이패드) 버전

## 1. 개요
아이폰 및 아이패드(iOS/iPadOS) 전용 Apple WebKit Standalone PWA 패키지입니다.

## 2. 아이폰 설치 방법 (Safari)
1. 아이폰의 **사파리(Safari)** 브라우저에서 이 웹 앱 URL(또는 index.html)을 엽니다.
2. 사파리 하단 가운데의 **[공유]** 버튼(네모에 위쪽 화살표)을 터치합니다.
3. 메뉴 목록에서 **[홈 화면에 추가]**를 누릅니다.
4. 우측 상단의 **[추가]**를 누르면 아이폰 바탕화면에 전용 앱 아이콘이 설치됩니다.
5. 바탕화면의 아이콘을 누르면 Safari 주소창 없이 **100% 전체화면 네이티브 앱**으로 구동됩니다.
