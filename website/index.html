누구나 1분 만에 시작하는 방법

복잡한 설정 없이 세 단계만 거치면 AI 주식 트레이더가 가동 준비를 마칩니다.

1

내 기기에 맞는 앱 받기

안드로이드폰은 메리츠_AI_주식.apk, PC는 메리츠_AI_주식_Setup.exe를 다운로드하거나 웹 버전을 바로 엽니다.

2

메리츠 연동 방식 선택

메리츠 SMART 앱으로 바로 열어 주문하거나, 메리츠 Open API App Key를 등록하여 원클릭 실전 자동 체결을 연동합니다.

3

AI 감시 시작 누르면 끝

상단의 [▶ AI 감시 시작]을 누르면 7중 안전 감시 엔진이 실시간 급등 유망주를 모니터링하며 매매를 돕습니다.
